# Autour du Monde

Mon tout premier site web, réalisé en **mai 2026**, au moment où je découvrais la programmation.

Je l'ai construit pour m'exercer à HTML et CSS, puis pour écrire mes toutes premières lignes de JavaScript.
## Pourquoi je le publie

Ce projet n'est pas une vitrine finie : je le publie pour montrer mes débuts et la progression qui a suivi. Le code est laissé tel que je l'avais écrit à l'époque, avec ses maladresses et ses pages inachevées.

Mes projets suivants, plus aboutis (React, Node.js, base de données, authentification), sont à voir sur mon profil.

## Ce qu'on y trouve

- Page d'accueil avec les destinations présentées sous forme de vignettes
- Check-list des indispensables avant de partir
- Générateur de destination au hasard
- Météo actuelle d'une ville, via l'API gratuite [Open-Meteo](https://open-meteo.com/) : ma première utilisation de `fetch`
- Pages « À propos » et « Contact »

## Technologies

- HTML5
- CSS3 (Flexbox)
- JavaScript (manipulation du DOM, `fetch` et `async/await`)

## Lancer le projet

Aucune installation nécessaire : ouvrir `index.html` dans un navigateur, ou utiliser l'extension Live Server de VS Code.
